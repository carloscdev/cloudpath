# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/)
y este proyecto sigue el [Versionado Semántico](https://semver.org/lang/es/) (`MAJOR.MINOR.PATCH`):

- **MAJOR** → Cambio arquitectural o rediseño completo de la plataforma.
- **MINOR** → Nuevo contenido, nuevas funcionalidades o mejoras significativas de calidad.
- **PATCH** → Correcciones de errores, ajustes de texto o pequeñas mejoras.

## [1.1.0] — 2026-06-04

## [1.0.0] — 2026-06-01

### 🎉 Lanzamiento inicial
- Plataforma **CloudPath** lanzada con soporte para dos cursos:
  - **AZ-900: Azure Fundamentals** (Microsoft Azure)
  - **AWS Cloud Practitioner CLF-C02** (Amazon Web Services)
- Interfaz con modo claro/oscuro y soporte i18n (ES/EN).
- Simulador de examen con **60 preguntas** por banco, retroalimentación inmediata y puntuación final.
- Contenido dividido en dominios con navegación por pestañas.
- Footer, navbar y tarjetas de cursos en la home.
